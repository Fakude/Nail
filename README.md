# Lashes by Nonnie

[![Validate and deploy site](https://github.com/Fakude/Nail/actions/workflows/pages.yml/badge.svg)](https://github.com/Fakude/Nail/actions/workflows/pages.yml)

A responsive static website for a lash and beauty studio. It presents services, a gallery, booking calls to action and WhatsApp contact options in a polished mobile-first layout.

## Run locally

Open `index.html` in a modern browser. No build step, package manager or server is required.

## Deployment

The `Validate and deploy site` GitHub Actions workflow checks every JavaScript file on pushes and pull requests. Pushes to `main` then deploy the site to GitHub Pages.

## Project structure

- `index.html` — page structure and accessible content
- `Nail.css` — responsive visual design
- `Nail.js` — interaction behaviour
- `1.jpg`–`5.jpg` — portfolio imagery
- `.github/workflows/pages.yml` — CI and GitHub Pages deployment

## Portfolio evidence

Demonstrates semantic HTML, responsive CSS, browser JavaScript, source control and continuous deployment through GitHub Actions.
